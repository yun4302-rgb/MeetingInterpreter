# 실시간 통역 회의록 — Android

갤럭시 S26 Ultra용 네이티브 Android 앱 프로젝트입니다.

## 주요 기능

- Android 시스템의 온디바이스 음성 인식 우선 사용
- ML Kit 오프라인 번역 언어팩을 이용한 외국어 → 한국어 통역
- 회의 전 선택 언어의 음성 인식팩·번역팩을 받는 언어팩 관리 버튼
- 한국어 회의 시 통역 없이 회의록만 기록
- 회의명, 시간, 장소, 업체별 참석자 입력
- 포그라운드 마이크 서비스와 CPU Wake Lock을 이용한 화면 꺼짐·백그라운드 기록
- 기기 내부 자동 저장 및 새 회의 Clear
- 핵심 논의, 결정 사항, Action Item 초안
- `Download/MeetingMinutes` 폴더에 Word `.doc` 회의록 저장
- 번역 API 키 또는 유료 서버 불필요

## 빌드 환경

- Android Studio Ladybug 이상
- JDK 17
- Android SDK 35
- Gradle 8.9
- minSdk 31 / targetSdk 35

이 프로젝트를 Android Studio에서 열고 Gradle 8.9로 동기화한 뒤 `Build > Build APK(s)`를 실행합니다. 이 실행 환경에는 Android SDK가 없어 APK 바이너리는 로컬 Android Studio 또는 CI에서 빌드해야 합니다.

## 최초 실행

1. 마이크와 알림 권한을 허용합니다.
2. 회의 언어를 선택합니다.
3. 최초 번역 언어팩 다운로드를 위해 인터넷에 연결합니다. 언어팩은 약 30MB입니다.
4. 이후 번역은 다운로드된 모델을 이용해 기기에서 처리됩니다.
5. `통역·기록 시작`을 누른 뒤 화면을 끄거나 다른 앱으로 전환해도 상단 알림의 포그라운드 서비스가 기록을 유지합니다.

온디바이스 음성 인식 언어팩이 없다는 메시지가 표시되면 갤럭시 설정의 음성 입력/언어팩 메뉴에서 해당 언어를 내려받은 후 다시 시작합니다.

## 개인정보

회의 메타데이터와 인식·번역 결과는 앱의 로컬 저장소에 보관됩니다. 번역 모델 다운로드 이후 ML Kit 번역 텍스트는 기기 내에서 처리됩니다. Android 시스템 음성 인식도 온디바이스 서비스가 제공되는 경우에만 앱이 시작되도록 구현되어 있습니다.
